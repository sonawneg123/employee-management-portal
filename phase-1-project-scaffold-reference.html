☕ Backend — Maven Dependencies Spring Boot 3 · Java 17

Core Framework

ArtifactVersionPurpose
spring-boot-starter-parent3.2.5 Parent POM — manages all Spring Boot dependency versions, plugin defaults, and encoding. Inheriting it means you never specify versions for Spring libraries individually.
spring-boot-starter-webmanaged Bundles Spring MVC, embedded Tomcat, Jackson (JSON), and all the plumbing needed to expose RESTful endpoints. The entry point for every HTTP request the server handles.

Persistence

ArtifactVersionPurpose
spring-boot-starter-data-jpamanaged Brings in Spring Data JPA + Hibernate ORM. Enables repository interfaces, entity management, JPQL queries, and automatic transaction management against any JPA datasource.
mysql-connector-jmanaged Official MySQL JDBC 8 driver. Runtime-scoped — only needed when the JVM boots, not during compilation. Connects Hibernate to the MySQL 8 server.

Security & JWT

ArtifactVersionPurpose
spring-boot-starter-securitymanaged Spring Security auto-configuration — provides authentication filters, method-level security (@PreAuthorize), CSRF, CORS integration, and password encoding via BCrypt.
jjwt-api0.12.5 Java JWT compile-time API (interfaces & builders). Allows creating and parsing signed JWT tokens without coupling to the implementation at compile time.
jjwt-impl0.12.5 Runtime implementation of the JJWT API. Handles HMAC-SHA256/512 signing and verification. Runtime-scoped because code depends only on the API artifact.
jjwt-jackson0.12.5 Jackson-based JSON serialisation adapter for JJWT. Allows claims to be read/written as standard Jackson objects. Runtime-scoped for the same reason as jjwt-impl.

Validation & DX

ArtifactVersionPurpose
spring-boot-starter-validationmanaged Hibernate Validator (JSR-380). Enables @Valid, @NotBlank, @Email, etc. on request DTOs, triggering automatic 400 responses for invalid payloads.
lombok1.18.32 Annotation processor that generates getters, setters, @Builder, @Slf4j, constructors, etc. at compile time. Eliminated from the final jar (optional=true).
mapstruct1.5.5.Final Compile-time DTO ↔ Entity mapper. Generates null-safe, type-safe mapping code without reflection — far faster than ModelMapper at runtime. Works hand-in-hand with Lombok via the annotation processor order in zpom.xml.
spring-boot-devtoolsmanaged Automatic class-reload and LiveReload during local development. Runtime + optional — stripped from production builds automatically.
spring-boot-starter-actuatormanaged Exposes /api/actuator/health, /metrics, /info endpoints. Plugs into Docker/Kubernetes health checks and monitoring tools like Prometheus.

Testing

ArtifactVersionPurpose
spring-boot-starter-testmanaged JUnit 5, Mockito, AssertJ, MockMvc, and Spring Test context loader bundled together. The standard Spring Boot test harness.
spring-security-testmanaged Adds @WithMockUser, SecurityMockMvcRequestPostProcessors, etc. so you can test secured endpoints without a running server.

⚛️ Frontend — npm Dependencies React 19 · Vite · MUI

Core UI

PackageVersionPurpose
react + react-dom^19.0.0 React 19 core. react is the library; react-dom is the DOM renderer. React 19 introduces the new compiler, server components support, and improved concurrent features.
react-router-dom^6.23.1 Client-side routing with nested routes, loaders, and <Outlet>. Used to define authenticated vs public route trees and navigate without full-page reloads.
@mui/material^5.15.20 Material UI component library — provides Buttons, Tables, Dialogs, Forms, AppBar, Drawer, etc. Built on Emotion for zero-config CSS-in-JS styling.
@mui/icons-material^5.15.20 2,000+ Material Design SVG icons as React components, pre-built for use with MUI's SvgIcon.
@emotion/react + @emotion/styled^11.x MUI's CSS-in-JS engine. @emotion/react provides css prop and theme; @emotion/styled enables styled(Component) syntax. Both are peer dependencies of MUI.

Data Fetching & State

PackageVersionPurpose
axios^1.7.2 HTTP client with interceptors. Used to attach JWT Authorization headers automatically on every request and to refresh tokens on 401 responses without manual wiring.
@tanstack/react-query^5.45.1 Server-state management — caching, background refetching, pagination, optimistic updates. Keeps the UI in sync with the backend without manual loading/error state boilerplate.
zustand^4.5.4 Minimal client-state store (auth user, theme preference, UI flags). Much lighter than Redux; no providers or reducers needed.

Forms & Validation

PackageVersionPurpose
react-hook-form^7.51.5 Performance-first form library that avoids re-renders on every keystroke. Integrates with MUI inputs via Controller.
@hookform/resolvers^3.4.2 Bridge between React Hook Form and schema validators like Yup. Lets you pass a Yup schema as the resolver option.
yup^1.4.0 Schema-based validation library. Defines field rules (required, min length, email format, etc.) that are evaluated by the hookform resolver before submission.

Utilities

PackageVersionPurpose
jwt-decode^4.0.0 Decodes a JWT payload on the client (no verification — that's the server's job). Used to extract user roles and token expiry without a network call.
dayjs^1.11.11 2 kB Moment.js replacement. Used to format dates in tables (date of joining, etc.) and validate date inputs.
react-toastify^10.0.5 Non-blocking toast notifications (success / error / info) triggered after API calls. Drop-in with zero MUI coupling.

Dev Dependencies

PackageVersionPurpose
vite^5.3.1 Next-generation build tool. Native ESM dev server with sub-100ms HMR, and Rollup-based production builds. Replaces Create React App.
@vitejs/plugin-react^4.3.1 Vite plugin that enables React fast-refresh (HMR) and JSX transform using Babel/SWC.
eslint + plugins^8.57 Static analysis. eslint-plugin-react + react-hooks enforce hooks rules and React best practices. react-refresh plugin prevents HMR pitfalls.
