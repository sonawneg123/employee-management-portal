2. Issues Found & Fixed

BUG   Issue 1 — rejectLeave field name mismatch

File: frontend/src/services/leaveApi.js · frontend/src/hooks/useLeaveHooks.js

Root Cause: The backend ReviewLeaveRequest DTO uses field rejectionReason, but the frontend hook was sending { reason: "…" } — an unknown field. Spring silently ignored it, leaving rejectionReason null on every rejection.

Fix: The useRejectLeave hook now maps the UI variable reason to the correct DTO field: { rejectionReason: reason }. JSDoc types updated in the service layer to match.

Test updated: src/tests/useLeaveHooks.test.jsx — assertion corrected to expect { rejectionReason: "Not approved" }.

BUG   Issue 2 — approveLeave sent no request body

File: frontend/src/services/leaveApi.js

Root Cause: axiosInstance.post(url) with no body argument sends a request without a Content-Type header. The endpoint declares consumes = APPLICATION_JSON, so Spring rejects the call with 415 Unsupported Media Type when the client omits the Content-Type entirely.

Fix: Changed to axiosInstance.post(url, {}) — an explicit empty JSON body ensures Axios sets Content-Type: application/json.

BUG   Issue 3 — SettingsPage used raw Axios error shape

File: frontend/src/pages/settings/SettingsPage.jsx

Root Cause: The page error handler read err.response?.data (raw Axios shape) instead of the normalised error object { message, violations } that axiosInstance throws after its response interceptor runs. As a result: (a) no violation errors were displayed, (b) general errors fell back to a blank message.

Fix: Replaced raw access pattern with the normalised shape: err?.violations for field errors and err?.message for general errors — consistent with every other page in the app.

DEAD CODE   Issue 4 — deleteAttendance called non-existent endpoint

File: frontend/src/services/attendanceApi.js

Root Cause: The service exported a deleteAttendance(id) function calling DELETE /attendance/{id}, but the backend AttendanceController has no DELETE endpoint — only GET, POST, PUT. Any call would produce a 405 Method Not Allowed.

Fix: Removed the dead deleteAttendance export. No component imported or called it.
